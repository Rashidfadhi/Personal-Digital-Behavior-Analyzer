# Personal Digital Behavior Analyzer

A Python desktop application that helps users track, analyze, and visualize their daily activities and time usage.

## 📌 Overview

Personal Digital Behavior Analyzer allows users to record activities with their category, duration, and date. The application analyzes the collected data and provides useful statistics, insights, behavior patterns, and visual charts.

## ✨ Features

- Add and manage activities
- Categorize activities
- Track activity duration
- Record activity dates
- Search activities
- Delete individual activities
- Clear all activities
- Import activities from CSV
- Export activities to CSV
- Store data using JSON
- Analyze total and average activity time
- Identify the longest session
- Find the most active category
- Analyze active days
- Generate behavior insights and patterns
- Visualize activity data with charts

The application provides four types of charts:

- **Category Distribution** – Displays category percentages
- **Statistics Chart** – Visualizes overall activity statistics
